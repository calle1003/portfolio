# Takao Akimoto — Portfolio

個人ポートフォリオサイトです。

## 公開手順（GitHub Pages）

1. GitHub のリポジトリ `Settings` → `Pages`
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / `/ (root)`
4. Save

公開 URL 例:

- `https://calle1003.github.io/portfolio/`
